# AI 적용 경계: 규칙 엔진과 AI의 역할 분담

이 문서는 과제에서 "AI를 어디에 쓰고 어디에 쓰지 않을지"를 정리한다. 발표 메시지와 평가 지표의 근거로 쓰며, 전체 기획은 [plan.md](plan.md)를 따른다.

## 핵심 메시지

> **반복 실행은 규칙 엔진이, 개선 설계는 AI가 한다.
> 하네스는 AI가 그 역할을 믿을 수 있게 수행하도록 만드는 장치다.**

이 과제는 "AI가 규칙보다 낫다"를 보이려는 것이 아니다. 규칙이 명확한 반복 업무는 규칙 엔진이 AI보다 싸고, 빠르고, 일관된다. AI가 시간과 비용 면에서 확실히 유리한 곳은 **규칙을 분석하고 고치는 시행착오 과정**이다. 이 구분을 숫자로 보여주는 것이 교육 효과의 핵심이다.

## 1. 반복 실행: 규칙 엔진이 유리한 영역

지시서 배정처럼 규칙이 명확하고 매일 수백 건 반복되는 판단이다.

| 항목 | 규칙 agent | AI agent |
|---|---|---|
| 건당 비용 | 사실상 0 | 약 $0.04~0.1 (추정) |
| 하루 150건 처리 | 1초 미만 | 수 분~수십 분, 약 $6~15 (추정) |
| 일관성 | 100% (결정적) | 반복할 때마다 결과가 달라짐 |
| 필수조건 위반 | 0건 | L3 이상에서 0건. 단, 규칙 엔진 검증기에 의존한 결과 |

AI agent 수치는 코드 구조를 보고 낸 추정치이며, M3 시범 실행의 실측값으로 바꾼다.

**교육 포인트**: 하네스 L3·L4에서 AI의 위반이 0건이 되는 것도 규칙 엔진의 `validate()` 덕분이다. 잘 만든 규칙 엔진은 AI로 대체할 대상이 아니라, AI를 안전하게 쓰기 위한 바탕이다.

## 2. 개선 설계: AI가 유리한 영역

실패 패턴 분석, 원인 가설, 규칙 파라미터 개선안 도출처럼 드물게 수행하고 정형화하기 어려운 판단이다. 기획서의 2~3단계에 해당한다.

| 근거 | 설명 |
|---|---|
| 시행착오 한 번이 싸다 | AI가 개선안을 내면 규칙 엔진이 10일치를 1초 안에, 추가 비용 없이 재시뮬레이션한다. 예: M2에서 P4 개선안(지역 완화 +1km)을 검증할 때 할당성공률 0.79 → 0.89를 1초 안에 확인했다. 사람이 하면 가설 → 수작업 집계 → 검증이 며칠 걸릴 수 있는 한 바퀴다. |
| 호출 빈도가 낮다 | 배정은 하루 150번 호출하지만, 개선 루프는 주나 달 단위로 몇 번이다. 건당 비용이 비싸도 전체 비용은 작다. |
| 판단이 비정형이다 | 여러 차원(지점·시간대·작업유형·사유)의 실패를 교차 분석하고 원인 가설을 세우는 일은 규칙으로 미리 써둘 수 없다. |
| 사람이 최종 승인한다 | AI는 제안하고, 규칙 엔진이 검증하고, 사람이 승인한다. 오류를 반영 전에 걸러낼 수 있다. |

## 3. 역할 분담 기준

| 판단 유형 | 빈도 | 규칙 명확성 | 담당 | 이 과제의 예 |
|---|---|---|---|---|
| 반복 실행 | 높음 | 명확 | 규칙 엔진 | 지시서 배정(solve), 필수조건 검증(validate) |
| 예외 처리 | 낮음 | 불명확 | AI + 규칙 엔진 검증 | 4단계: 규칙 엔진이 못 푼 잔여 건 추천 |
| 개선 설계 | 낮음 | 불명확 | AI + 시뮬레이션 + 사람 승인 | 2~3단계: 실패 패턴 분석, 파라미터 개선안 |
| 최종 반영 | 낮음 | — | 사람 | 개선안 승인·반려 |

4단계(잔여 건만 AI가 처리)도 같은 논리를 따른다. 건수가 적고 예외적인 경우에만 AI의 비용을 쓴다.

## 4. 측정 방법

주장을 숫자로 보이기 위해 아래 지표를 수집한다. [plan.md 8장](plan.md#8-평가-지표)에도 반영되어 있다.

| 마일스톤 | 지표 | 비교 대상 |
|---|---|---|
| M3 | 건당 비용(토큰 비용)과 처리 시간 | 규칙 agent($0, 초 단위) vs AI agent 하네스 레벨별 |
| M3 | 품질 지표(할당성공률, 위반 건수)와 비용을 같은 표에 표시 | "하네스로 품질은 따라잡았지만 비용 차이는 크다"를 그대로 보여준다 |
| M4 | 개선 1회전 비용 = 분석·제안 LLM 비용 + 시뮬레이션 시간 | 같은 분석을 사람이 할 때의 추정 소요 시간(현업 담당자 확인) |
| M4 | 개선 1회전당 할당성공률 변화 | 회차별 추이 |

**실험 비용 배분**: 배정 실험(M3)은 하네스 효과를 보여줄 만큼만 돌린다(1일치, 대표 레벨만 반복). 아낀 비용은 개선 루프(M4)를 여러 번 도는 데 쓴다.
